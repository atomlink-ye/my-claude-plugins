# Paseo Reminder compatibility entrypoint

`paseo-reminder` now runs from the standalone [Agent Runtime Control Panel](../../agent-runtime-control-panel/).
The historic package path, scripts, environment names (`PASEO_COMPANION_DATA` and
`PASEO_COMPANION_RUNTIME_DIR`) and unversioned HTTP routes remain supported. Build and
operate the runtime from `skills/agent-runtime-control-panel/runtime` going forward.
